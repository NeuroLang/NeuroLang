API Reference#

Complete API documentation for all public NeuroLang modules. Generated automatically from docstrings.

Most users only need the two frontend classes below: NeurolangDL for deterministic Datalog and NeurolangPDL for probabilistic Datalog. Their most used methods are add_tuple_set, add_atlas_set, add_symbol, add_probabilistic_facts_from_tuples, add_probabilistic_choice_from_tuples, add_uniform_probabilistic_choice_over_set, execute_datalog_program, execute_squall_program, query and solve_all.
